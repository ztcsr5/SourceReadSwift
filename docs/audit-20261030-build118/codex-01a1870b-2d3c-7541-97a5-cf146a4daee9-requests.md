   - **根因**：
     - **容器背景缺失/透明**：承载单页内容的页面容器（如 `.page-container` 或 Reader View）的 `background-color` 未被显式设置为纯色不透明（`opaque`），导致在执行 `transform` 或翻页动画时，两个图层（Layer）在 GPU 合成器中直接进行了混合渲染（Alpha Blending）。
     - **旧页面 DOM 未卸载/隐藏**：换页后上一页的 DOM 节点未及时被 `display: none`、`visibility: hidden` 或移出渲染树，两个页面同时挂载在视图层中。
2. **手势跟手与动画不同步（Transform & Paging Offset Jitter）**

   - **根因**：
     - **原生手势与 WebView 事件竞争（Touch Event Throttling）**：如果翻页手势是由 JS 的 `touchmove` / `touchend` 监听处理，在复杂的 DOM 树或重排期间容易丢帧；若是原生 `UIPanGestureRecognizer` 驱动，则可能在向 WebView 同步 `translateX` 矩阵时发生了帧率不同步。
     - **CSS 过渡未重置**：在拖拽过程中未将 `transition` 设为 `none`，导致实时手势位移与 CSS 的缓动动画发生冲突拉扯；松手时页码边界判断（Threshold）计算出错。
