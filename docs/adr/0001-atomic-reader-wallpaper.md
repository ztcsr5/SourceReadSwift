# ADR 0001 · 壁纸图片与编辑参数原子提交

## 背景
选图即覆盖会让取消编辑失效；分别写 JPEG 与裁切参数会在部分失败时产生不匹配的状态。大图解码也不应阻塞阅读页面主线程。

## 选项
- 独立 JPEG 与偏好：沿用旧结构，但无法把两次写入合并成一次提交。
- 图片和参数单个版本化文件：有 Base64 体积开销，但一次原子替换即可提交完整状态。

## 决定
使用有大小限制的 v2 JSON 信封保存降采样 JPEG 和校验后的编辑参数，Foundation 原子写入；磁盘和图片处理在后台任务执行。编辑草稿只保存在内存，明确应用后才写入。保留旧 JPEG 只读兼容，不在升级保存时删除。缩略预览保持当前阅读视口比例，不承诺缩略文字等同实际正文排版。

## 后果
不增加依赖，不修改书架或阅读位置格式。保存失败保留原有效记录；取消不写入；删除需要确认。回退应用代码仍可读取保留的旧 JPEG，但不能理解 v2 新编辑参数；回退前应保留 v2 文件供重新升级恢复，不能用清理命令删除用户文件。
