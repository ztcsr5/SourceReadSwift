## 本次实质变更

- 补齐执行到解析阶段才发生的脚本子请求摘要。导出仅记录请求方法与字节数、常见版本字段及会话头在构建边界是否出现、HTTP 状态和响应类型；从不记录这些字段的内容、第二层请求 URL、会话值或正文。只识别查询和 JSON/表单的顶层字段；未检查、或未识别到字段，都不等于加密数据内部没有。HTTP 200 也不证明可读或登录有效。
- 目录脚本收到明确的鉴权/拒绝响应且没有解析出章节时，保留这个错误，不再交另一套解析器重复执行同一脚本。没有改站点版本值、验证要求、证书校验，也没有修改作者的规则文件。
- 复现用例覆盖外层数据成功而正文脚本返回更新提示，并验证导出有真实子请求摘要但没有敏感值；另一用例验证目录遇到 HTTP 401 不重发。
