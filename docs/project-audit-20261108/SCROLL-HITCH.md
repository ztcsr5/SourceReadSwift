## 已复现与修正

- 原文档在章间留白捕获锚点时，把负位移钳为零。裁掉旧章节/前插章节后，下一标题跳 22.75 / 22.25 px；生产 HTML 回归先红，修复后偏差小于 1 px。保留正文内按高度比例恢复字体变化的语义。
- 章节到达后的 DOM 注入没有感知原生拖动和惯性。非紧急补丁改为等待空闲、只挂载最新窗口；距文档末尾不足三屏仍及时追加，顶部反向加载及主动跳章不等待。
- 原生拖动/惯性阶段不裁剪前方章节，结束后再执行既有有界窗口策略，避免补偿性 scrollTo 打断惯性。
