# 隙光品牌与七套色彩沙龙

## 图标

图形采用斜向、带切口的环形负空间，命名「隙光」。保留“纸间”的间隙意象，去掉书本、书签、字母、星星与复杂小图形。可可棕底色衬托长春花蓝主体，胭脂粉切面和苔绿窄边形成材质区分。小尺寸保留一个清晰轮廓，不把所有配色均分为彩虹。

- 主体长春花蓝 `#B9BCF0`；底色可可棕 `#392B2B`；胭脂粉 `#E8B5BC`；苔绿 `#82917C`。
- 使用原项目 Pillow 图标工具链重新设计，不联网调用生成模型，不增加 App 依赖。
- 1024 × 1024 RGB 无透明 AppIcon；App 内设置/关于采用同一个品牌图形的 192 px 资源。
- 已检查 40 / 60 / 120 px 缩略图。iOS 系统圆角由系统裁切，原 AppIcon 不预烘焙透明圆角。
- 可复现命令：`python -B -X utf8 scripts/generate_master_app_icon.py`。
- `ICON-REVIEW.png` 是设计预览，不是 iOS 运行截图。

影响首页阅读卡、书架陈列、各页面纸面、通用卡片与浮动控件。外观设置单列「色彩沙龙」；原主题持久化键不变，原默认森林绿不替换。

用户补充参考图后，原四套主题按上述原始双色重新校准，并追加星墨、松雾、蓝艾，共七套可选主题。长春花蓝采用明确的 RGB 123 / 136 / 215；新增三组统一采用用户给出的 HEX，松针绿与雾灰白不采用图中冲突的 RGB 数字。`AppAtelierPalette` 独立保存每组原始色，应用于阅读卡进度色块、底栏选中态与搜索按钮、详情阅读/下载入口、设置色样及印刷装饰。筛选选中态、剪贴板导入按钮与书源体检横幅也使用相同的填色/文字令牌，避免深色模式沿用白字加浅色 accent。每套只使用自己的一组颜色，原四套布局、底栏尺寸/边框/点击范围与其它主题保持原样。

普通文字与链接使用明暗衍生色，原始色块配专用深字色。长春花蓝与原可可棕的对比度为 2.40，不能用于小字，因此蓝色块上的文字采用深可可 `#100B08`；桃苔色块文字用深苔 `#304131`，给现有按压透明度保留可读余量。原可可与苔青仍用于装饰、色样及其它可读位置。黑色文字始终放在粉色块上，深色模式下不会出现黑字黑底。原始色块在默认状态不透明，明暗模式都保持相同且可读的配对。

星墨的原始星紫即使搭配纯黑文字，现有 0.84 按压透明度下对比度仍会跌到 4.00，因此互动色块采用同色相亮紫 `#B873F8` 配墨黑；原始 `#A855F7` 保留在定位装饰和双色色样中。松雾使用原雾灰白色块配深松针 `#29482F`；蓝艾直接使用原艾绿色块配原克莱因蓝文字。七套的原始 pair 均有精确值断言，星墨的衍生互动色另有精确值与按压对比度断言，4.5 验收标准未降低。
