# 隙光品牌与四套色彩沙龙

## 图标

图形采用斜向、带切口的环形负空间，命名「隙光」。保留“纸间”的间隙意象，去掉书本、书签、字母、星星与复杂小图形。可可棕底色衬托长春花蓝主体，胭脂粉切面和苔绿窄边形成材质区分。小尺寸保留一个清晰轮廓，不把所有配色均分为彩虹。

- 主体长春花蓝 `#B9BCF0`；底色可可棕 `#392B2B`；胭脂粉 `#E8B5BC`；苔绿 `#82917C`。
- 使用原项目 Pillow 图标工具链重新设计，不联网调用生成模型，不增加 App 依赖。
- 1024 × 1024 RGB 无透明 AppIcon；App 内设置/关于采用同一个品牌图形的 192 px 资源。
- 已检查 40 / 60 / 120 px 缩略图。iOS 系统圆角由系统裁切，原 AppIcon 不预烘焙透明圆角。
- 可复现命令：`python -B -X utf8 scripts/generate_master_app_icon.py`。
- `ICON-REVIEW.png` 是设计预览，不是 iOS 运行截图。

## 全局主题

| 主题 | 双主色 | 结构与材质 |
|---|---|---|
| 莓湖 · 艺术季刊 | 浆果红 + 湖蓝 | 分栏阅读卡、裁角纸页、双色侧边印刷线 |
| 胭墨 · 夜场画廊 | 胭脂粉 + 墨黑 | 紧凑书架索引、窄边刻度、平整纸面 |
| 隙光 · 可可沙龙 | 长春花蓝 + 可可棕 | 双列陈列、圆弧留白、宽圆角奶油纸面 |
| 桃苔 · 静谧庭院 | 裸桃粉 + 苔青绿 | 双列画廊、内缩压印边框、细短色签 |

影响首页阅读卡、书架陈列、各页面纸面、通用卡片与浮动控件。外观设置单列「色彩沙龙」；原主题持久化键不变，原默认森林绿不替换。

明暗模式分别配色。为保证小字可读，浅色粉/蓝用于底色与装饰，文字与操作使用同色相的较深颜色。对新主题两种操作色分别与纸面、卡片背景检查，最小对比度：莓湖 5.64、胭墨 5.37、隙光 4.82、桃苔 4.97，均高于 4.5。没有增加连续动画、实时模糊或滚动时纹理生成。
