# 逐项验收对照（给真机测试用）

> 分支 `codex/reader-feedback-fixes`，远端最新提交见文末。
> 每条格式：**现象 → 改了什么 → 怎么验 → 预期**。全部改动已通过 iOS workflow（Build + 全量 XCTest）与 Unsigned IPA 两条 CI。

## 1. 主页比例 / 左上角入口 / 白块

- 改：`BookshelfView.swift` — 删 `navigationBarLeading` 的「管理」；hero 卡 312×246 → 300×190（封面 66×92、内距 16、去掉无动作的「…」）；间距 30 → 26、底留白 30；`AsyncBookCover` 新增 `style`，白卡用 `primary 0.06` 占位。
- 验：冷启动进主页 → 看「正在阅读」卡片高度是否不再占掉半屏；看左上角是否只有大标题；书架里没有封面的书是否还是一块白板。
- 预期：卡片略矮、下方能看到第二行书卡；左上角空白；占位块是浅灰底 + 灰色书图标。

## 2. 打开位置 / 恢复偏移

- 改：`NativeReaderTextView` 新增 `topInset`（工具栏显隐时 56 / 约 30，改 inset 时补偿 `contentOffset`）、`onScrollTargetApplied`；`ReaderView` 新增 `initialSurfaceOpacity`（定位落地前透明，0.5s 兜底）。
- 验：① 一本从没读过的书，打开看章标题离状态栏的距离；② 读到第 3 章中间退出，再进同一本；③ 打开后立刻点屏幕中间（透明窗口期）。
- 预期：① 标题贴近安全区下沿，不再空出一大条；② 直接落在上次位置，**不出现“先闪章首再跳”**；③ 透明期点击不会误触文字。

## 3. 下滑白条

- 改：文字层不再 `.clear`，由 `surfaceColor` 自铺主题底色（`updateInsets` 里设置）。
- 验：浅色主题 + 白底书，快速下滑到章尾，再回弹到顶部。
- 预期：全程无白色横条；换章占位期间也是主题色。

## 4. 本地书详情闪退 / 空状态

- 改：`BookDetailView.load()` 增加 `sourceUrl.hasPrefix("local://")` 分支，详情与章节直接取 `bookshelfStore.book(id:)?.localChapters`，不进 `SourceEngine`。
- 验：书架里长按一本本地 TXT → 书籍详情；再试 EPUB 导入的书。
- 预期：直接显示书名/作者/简介 + 完整目录（章节数与本地一致），不再出现「找不到书源：Local」或闪退回主页；「缓存」按钮仍按设计置灰（本地书没有远端缓存）。

## 5. 章节进度条

- 改：拖动中每 120ms 防抖落章（`chapterSeekTask`），面板顶部实时显示「第 N / M 章」；松手立即落章；拖动期间不关设置面板（`selectChapter(keepChrome:)`）。
- 验：打开一本 100 章以上的书，按住进度条从 10% 拖到 60%，中途停住不动 0.3 秒。
- 预期：停住就跳章并显示落点文案；继续拖会继续跟；松手停在最终章；面板不会消失。

## 7. 连点「下一页」乱跳 / 卡死

- 改：`applyPageStep` 加排队（`isPageStepping` / `pendingPageStepDirection`），动画中只记方向，不再对飞行中的 `contentOffset` 重算目标。
- 验：滑动模式连点右侧「下一页」5 次；再连点左侧 5 次。
- 预期：每次正好一屏，方向一致，不出现“第二下几乎不动、第三下跳一大截”，也不会卡住。

## 8. 主题色重复 / 自定义纯黑进不去

- 改：`ReaderBackground.pickerCases`（16 → 11，去同色）、自定义壁纸入口上移到色卡下方并加提示；`ReaderBackgroundPickerTests` 锁死这些约束。
- 验：外观 → 背景颜色数一遍色卡；选「自定义」后看下方是否有导入入口。
- 预期：11 个色卡，没有两个看起来一样的；选自定义立刻能看到「从相册选择壁纸」；选完壁纸正文立刻换背景。

## 9. 覆盖模式边框

- 改：`pageSurface` 的 cover 分支删掉重复的 `shadow(radius:14, x:-6)`，只保留 `coverPagedReaderContent` 每页的方向阴影。
- 验：覆盖模式左右各拖一次半页。
- 预期：只有被拖起那一侧有单层柔和阴影，不再有“双层黑框”。

## 10. 上下主题色不一致

- 改：顶栏与设置面板的 material 由 `.regularMaterial` 统一为 `.ultraThinMaterial`；文字层自铺底色。
- 验：依次切 5 个主题（羊皮纸 / 豆沙绿 / 青空 / 夜樱 / 极黑），每次看顶栏、正文、底栏。
- 预期：三段同色系，没有“上面偏亮、下面偏暗”。

## 11. 本地声音

- 改：`TTSEngineKind.file` + `LocalVoiceLibrary`（`Documents/local_voice`，段落序号命名）+ `CloudTTSPlayer.play(fileURL:)` + 设置页导入区。
- 验：`语音朗读 → 引擎选「本地声音」→ 导入 0.mp3、1.mp3`，然后正文朗读。
- 预期：第 1 段播 0.mp3、第 2 段播 1.mp3、第 3 段没文件则跳过；暂停/继续/上下段/锁屏控制与讯飞通道一致；没导入时提示回退系统语音。

## 13. 全屏页脚

- 改：页脚 20pt 高居中 + `6 + home indicator` 底部间距；时间/电量图标/百分比三个独立开关。
- 验：全屏（工具栏隐藏）看页脚；再关掉“显示电量百分比”看一次。
- 预期：文字离开底部横条约 34pt；关掉后位置不跳、只少一项；三项全关时页脚为空且不占位。

## 14. 滑动卡壳 / 回弹

- 改：章节加载回调从滚动帧挪到下一个 runloop；滑动中遇到整窗变更时推迟重建（`ReaderRebuildDeferralPolicy`），惯性结束按字符锚点补做。
- 验：长章节快速滑到章尾，让下一章在滑动中到达；再在章界继续快滑。
- 预期：不出现“滑到一半顿住再弹回”；章界文字在**手停下后**才替换（看到的是占位页 → 内容），位置不跳。

## 12. 滑动帧率（未收尾，等真机数字）

- 已做：正文段落数组按指纹缓存；滑动期延迟重建；DEBUG 探针 `ReaderPerf`。
- 验：Xcode Debug 真机，Console 过滤 `ReaderPerf`，长章节滑 10 秒 + 章界滑一次。
- 需要你回传：`avg / worst` 一行。判定见 `读者反馈修复清单.md` 第六节。
