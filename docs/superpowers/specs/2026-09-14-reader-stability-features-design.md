# 阅读器核心稳定性重构与进阶功能设计规范

- 日期：2026-09-14
- 目标：解决用户提出的 8 大核心痛点，吸收 cmbok_app 优秀特性，彻底重塑朗读、自动滚动与上下滑动阅读体验，补齐一键换源、离线缓存、批量体检导出等关键能力，确保 1000+ 书源下丝滑流畅不闪退。

---

## 一、核心痛点与攻坚目标

1. **书源多了一键测试直接闪退**：根除 1000 个源测试时的内存暴涨、频繁同步刷盘与 Watchdog 0x8badf00d 超时崩溃。
2. **一键测试导出详细报告**：导出格式化 Markdown 与 JSON 文件（调起 iOS 系统分享与存储到文件），精准到每个书源的失败阶段与根本原因，并给出直观的修复建议。
3. **阅读界面底栏对齐与进度条拉长**：「上一章」「下一章」与底下的「目录」「设置」严格垂直对齐，中间章节进度条拉长铺满全部剩余空间。
4. **覆盖翻页模式重叠冲突**：将半透明改为 100% 实心底色，移除外边距透光，消除文字透字重叠，保留立体侧边阴影。
5. **上下滑动模式防止点击乱跑**：滑动模式禁用左右点击跳段，仅保留屏幕中间点击呼出菜单；底栏切章重置视口位置，杜绝无限滑动死循环。
6. **重构朗读功能（TTS）**：实现段落朗读视口自动跟随居中高亮、跨章无缝连读、后台音频与锁屏控制中心（Now Playing & 灵动岛），彻底治愈卡住不动与息屏断播。
7. **重构自动滚动功能**：采用 CADisplayLink 60FPS 像素级平滑匀速向下推进，替代原有的突兀跳段抽搐；底部无感衔接下一章，轻触即稳停。
8. **很多能搜索但正文加载失败攻坚**：构建四级正文容错体系（修复规则后接 JS 解析 Bug、匹配 95% 通用网文容器、智能文本密度抽取兜底、WebView 动态验证盾兜底）。
9. **搜索结果按书聚合（方案 A）**：搜“斗破苍穹”按书籍聚合为一列一列卡片，标明“X 个书源可用”与最新章节，支持换源与模式切换，渲染组件减少 90%+。
10. **大容量性能加固与实用功能集合**：
    - 阅读器内「一键智能换源」（无需退出阅读器直接切源对齐章节）；
    - 批量离线缓存管理器（下载后 50 章 / 全本下载，断网离线读）；
    - 测试后「一键禁用所有失败书源」；
    - 书源分组快捷标签与状态过滤栏；
    - WiFi 局域网网页传书（本地 TXT/EPUB 拖拽导入）；
    - 书架下拉「追更检测」与红点角标；
    - 书架分类分组管理（正在追 / 完结 / 养肥）。

## 二、详细技术设计方案

### 1. 一键测试防闪退与详细诊断报告导出
- **防闪退改造**：
  - 修改 `SourceManagerView.swift` 与 `SourceBatchCheckState`：移除每次测试完单源时的 4 次全量同步 JSON 写盘（`sourceHealthStore` 与 `sourceDiagnosticHistoryStore`）。
  - 将单源测试结果在内存中安全累积，引入 250ms 节流定时器批量汇报 UI 状态，避免每秒发生数十次 SwiftUI 全列表 Diff 重绘。
  - 测试结束、取消或每 50 个批次时，执行一次性后台异步批量持久化。
  - 不在内存中持有 1000 个完整的 HTML 响应与 DOM 树，改用轻量级 `SourceBatchDiagnosticSummary` 摘要模型，节约 80% 内存。
- **详细报告生成与文件导出**：
  - 新增 `SourceDiagnosticReportExporter`：将体检数据格式化为 Markdown 报告与 JSON 诊断包。
  - 报告结构：
    1. 概览：测试时间、关键词、总数、通过/警告/失败/拦截数量统计。
    2. 问题分类与解决建议：
       - 域名/网络失效（超时/404）：提示检查域名有效性或开启代理；
       - 反爬风控（Cloudflare/百度验证）：提示书源开启 `webView` 或网页登录；
       - 正文为空（content.parse）：提示适配正文规则选择器；
       - 目录为空（toc.parse）：提示更新章节列表规则。
    3. 全量明细列表：列出每个源的状态、耗时、失败阶段、状态码与修复字段建议。
  - UI 增加「导出报告文件」按钮，调用系统 `UIActivityViewController` / `ShareLink`，支持一键「存储到文件」、AirDrop、微信分享。
  - 弹窗底部增加「一键禁用所有失败书源」按钮，一键批量修改状态并保存。

### 2. 彻底解决正文加载失败：四级正文容错体系
- **第一级：原生规则与 JS 兼容修复**：
  - 修改 `HtmlRuleExtractor.swift`：支持 CSS 规则后接 `@js:` 或 `<js>...</js>`（如 `id.content@html@js:result`）。先抽取 DOM 内容，再将其作为 `result` 传给 JSCore 执行脚本，恢复 43+ 个含脚本书源的正文解析。
  - 完善 `SourceURLDirectiveParser` 与 `SourceEngine` 对 `webJs` 包含 `{"webView": true}` 的识别。
- **第二级：网文通用正文容器匹配**：
  - 在 `ContentParser.swift` 中，当书源指定的 `ruleContent.content` 规则解析结果为空时，自动尝试匹配各大网文站 95% 通用容器：
    `#content, #chaptercontent, #BookText, #htmlContent, .read-content, .content, .showtxt, article, div.entry-content`。
- **第三级：智能文本密度提取（SmartWebArticleExtractor）**：
  - 若第二级仍未找到内容，自动调用 `SmartWebArticleExtractor.extract(html: response.body)`，根据段落文字密度自动过滤掉导航、版权声明、广告与脚本，提取正文段落。
- **第四级：WebView 自动兜底**：
  - 当响应状态码为 403/503 或正文包含 Cloudflare/验证码特征时，自动无头唤起 `WebViewFallback` 进行真实浏览器渲染并捕获最终生成的正文内容。

### 3. 阅读界面底栏对齐与超长进度条
- **修改文件**：`ReaderView.swift`
- **对齐与布局调整**：
  - 将底栏第一行的「上一章」宽度设置为固定 54pt（居左，垂直精准对齐第二行首个按钮「目录」）。
  - 将「下一章」宽度设置为固定 54pt（居右，垂直精准对齐第二行末尾按钮「设置」）。
  - 中间 Slider 使用 `.frame(maxWidth: .infinity)`，横向扩展拉长至铺满剩余全部空间，跨度提升近 2 倍，拖动选章更加舒适。

### 4. 覆盖翻页模式消除文字重叠
- **修改文件**：`ReaderView.swift` 中的 `pageSurface` 与 `coverPagedReaderContent`
- **彻底消除重叠方案**：
  - 移除背景矩形的半透明属性（原 `background.color.opacity(0.92~0.98)`），强制设定为 **100% 实心不透明底色**。
  - 移除原有的 `.padding(.vertical, 8).padding(.horizontal, 4)`，让页面实心背景 100% 占满整个屏幕，新滑入的页面完全覆盖底层页面，阻断底层文字穿透。
  - 仅在滑入页面的左边缘保留侧边阴影投影（Drop Shadow），营造逼真的实体纸张覆盖层次感。

### 5. 上下滑动模式彻底消除“点击乱跑”
- **修改文件**：`ReaderView.swift` 中的 `runTapAction` 与 `moveReaderTarget`
- **稳定性方案**：
  - 在滑动（Scroll）模式下，`runTapAction` 中加入防御判断：如果 `readerMode == .scroll`，仅响应 `.menu`（中间呼出菜单），直接忽略左/右点击触发的 `.previousPage` / `.nextPage`，从物理上消除误触乱跑。
  - 底栏点击「上一章」或「下一章」切章时，清空 `appendedSections` 并将滚动位置重置为新章节顶部 (y = 0)，防止新旧章节在后台并发加载冲突导致视口反复拉扯。

### 6. 重塑朗读功能（TTS 视口跟随、无缝跨章与后台播放）
- **修改文件**：`ReaderView.swift` 与 `ReaderSpeechController`
- **增强特性**：
  - **视口跟读自动居中**：在 `onChange(of: speechController.currentParagraphIndex)` 中，滑动模式通过 NativeReaderTextView 平滑将当前段落滚动至屏幕纵向约 35%~50% 的舒适视线区域，并保持段落背景高亮。
  - **跨章无缝连读**：当朗读队列播完当前章最后一段时，触发自动切入下一章第 1 段并继续朗读，连绵不断畅听。
  - **后台与锁屏播放（Now Playing）**：配置 `AVAudioSession` 为 `.playback`，结合 `MPNowPlayingInfoCenter` 汇报书名、作者与当前章节名，支持锁屏与灵动岛切章/暂停。

### 7. 重塑自动滚动功能（60FPS 丝滑平滑下卷）
- **修改文件**：`ReaderView.swift` 与 `NativeReaderTextView.swift`
- **重构方案**：
  - 废弃原来每隔数秒发一次 `ParagraphJumpRequest` 的抽搐硬跳段逻辑。
  - 采用 `CADisplayLink` 或 60FPS 微步计时器，控制 `UITextView` 的 `contentOffset.y` 按恒定像素速度（如每秒 30~50pt，可按 1x~5x 调节）匀速平缓下滚。
  - 接近底部时后台预拉取并平滑拼接下一章，手指轻触屏幕任何区域瞬间稳妥暂停。

### 8. 搜索结果按书籍聚合（方案 A）
- **修改文件**：`DiscoverView.swift`
- **聚合设计**：
  - 定义 `AggregatedSearchBook` 模型（以规范化的 `title + author` 为主键）。
  - 将所有书源返回的搜索结果归集到对应的书籍卡片中，卡片展示：书名、作者、最新章节、可用书源数量徽标（如“42 个书源”）。
  - 点击书籍卡片进入多源详情页或展开各书源列表，用户可直观对比各源的最新章节和响应速度，一键选用最优书源。
  - 顶部提供 SegmentedControl 切换「按书籍聚合」与「按书源分组」，满足不同习惯。
  - 视图卡片数量减少 90%+，彻底根治大规模搜索引发的界面卡死。

### 9. 进阶杀手级功能实现
- **阅读器内「一键智能换源」**：在阅读器菜单增加「换源」按钮，弹出当前书籍的多源列表，点击秒级无缝换源并自动对齐阅读章节。
- **批量离线缓存管理**：详情页与阅读器设置增加离线缓存管理器，支持「下载后续 50 章」、「下载全本」、「下载未读章节」，显示下载进度条。
- **书源分组快捷标签与过滤**：书源管理顶部增加横向胶囊分组切换，支持按分组一键批量开关。
- **WiFi 局域网网页传书**：书架支持本地启动小型 HTTP 服务，电脑端浏览器拖拽直接将 TXT/EPUB 传至手机书架并智能切章。
- **书架下拉追更检测**：书架下拉刷新并发检查在追图书最新章节，封面右上角标注「更新至第 X 章」红色角标。
- **书架分类分组管理**：支持将书架图书分类归集（正在追、完结、养肥、自定义书架）。

### 10. 阅读器顶部安全留白与下移防遮挡（新增反馈）
- **问题根因**：阅读器使用 `.ignoresSafeArea()`，但原 `insets.top` 和 `pagePadding` 仅约 16pt，远小于 iPhone 灵动岛 / 刘海高度（44~59pt），导致点进新书时顶部章节标题和首行文字被灵动岛遮挡，用户必须往下拉才能看清。
- **解决方案**：
  - 在 `NativeReaderTextView.swift` 的 `updateInsets` 中，将顶部边距调整为计算系统 Safe Area 顶部高度或增加充足的顶部留白（`topInset = max(safeAreaTop, 48) + 12`，保持约 54~60pt 的舒适沉浸间距）；
  - 在翻页模式的 `pageSurface` 增加顶部安全间距，确保任何机型点开章节时，标题与正文自然位于灵动岛下方，呼吸感充足。

### 11. 全面深度增强书源解析能力（新增反馈）
- **全面适配复杂书源**：
  - 增强 `HtmlRuleExtractor.swift`：支持 CSS 选择器链后接 `@js:` 或 `<js>` 动态解密、多索引切割（如 `div.content@all
@js:...`）；
  - 章节 URL 相对路径智能解析：优先使用 `chapter.bookUrl` 或 TOC 响应最终重定向 URL 作为 base，杜绝子路径解析为域名根路径导致的 404；
  - 增强 JSON 解析器：支持复杂嵌套数组切片、多层级 JSONPath 及动态变量替换；
  - 自动识别并适配含有反爬动态 JS 或无头浏览器需求的书源。
