## 核心验收

| 场景 | 操作 | 应观察的结果 |
|---|---|---|
| 原始裁字复现 | 内置阅读示例最后一章，20号字、8行距、16段距，翻到原来底部裁字的页 | 页面最后一行完整，下一页衔接无缺字/重字；不同手机几何需另验 |
| 纯中文/混排 | 切换不同字号、行距、标题内嵌；测试中文、英文、emoji和长段落 | 排版更新，不出现旧页缓存或丢尾；进度仍在原文附近 |
| 连续翻页 | 覆盖模式同方向连续划20次，再交替快速正反划；动画中再次起手 | 页面提交次数与完成的有效手势对应，不吞后续手势，不回闪旧页 |
| 取消与边界 | 短拖后回弹；书首向前/书尾向后；拖动中退出阅读页再进入 | 不误翻、不卡住，不在退出后提交迟到翻页 |
| 覆盖/平移区别 | 同一页分别切两种模式缓慢拖动 | 覆盖为层叠露出，平移为整页并排移动，不是同一动画改名 |
| 原生仿真 | 切仿真模式，拖页角、取消、连续跨章、开关菜单 | 使用原生卷页，无旧自定义假仿真；跨章/取消还需实际触控验收 |
| 原生更多菜单 | 点击更多按钮、执行有权限的动作、取消菜单 | 系统UIMenu，原黑色浮层消失，不截走正文手势 |
| 设置层级 | 阅读页打开/关闭字体、翻页等设置，重复操作 | 保留118已经修好的层级，不出现设置夹在正文中间 |
| 冷章节 | 跳到未预热的章节，随后连续向前/后翻 | 占位转正文后更新；不永远停留旧邻页，不卡死 |
| 图片/漫画 | 图片混排章节、超长图片、纯图片章节 | 必须单独验收；本轮没有重写旧图片分页引擎 |

## 证据边界

XCTest已经覆盖真实UITextView排版与控制器状态事务，但不代表设备帧率、触控手感、系统菜单呈现和全部书籍均已验收。设备未通过项应按上表条件采集，不能用“所有测试绿灯”否定实际反馈。
