## 可直接试用的路径

| 入口 | 预期行为 |
|---|---|
| 阅读器 → 翻页 → 无动画 | 轻触或完成一次有效拖动后直接换页；拖动中原页不平移，取消手势不翻页。平移、覆盖、仿真各自保留。 |
| 设置 → 阅读排版；或阅读器内排版 | 下划线只用于正文，默认关。原预设之外新增「模版1」：左上章节名、左下页码与进度、右下时间和电量；关闭还原开启前排版，不改书签、进度、翻页方式和阅读纸。 |
| 阅读排版 → 段评与互动样式 | 默认关。开启后，滚动的气泡定位到段或章；分页入口只列本页相关段评和章评。没有可识别入口的书不显示假按钮。可以选择文字/精简气泡、跟随主题色/自选色、卡片玻璃浓度、不透明度及圆角。 |
| 设置 → 书源管理 → 书源工具；设置 → 离线书库；关于纸间 → 右上角 | 分别进入 AI/Web 写源、离线章节/漫画、读者 QQ 群。移动的是入口，不移动或清空下载和书源。 |

参考包 `栖阅2027.01.01.ipa`（14,434,884 B，SHA-256 `28c0a2b7538c6c64ebeb13b63bfa460547c7ee464dd81ac0bf377a505aed9ea2`）仅用于确认版式。其 `reader.css` 的参考值为字号 18 px、行高 28 px、段距 10 px、左右各 20 px、首行缩进 2 em。`ReaderReferenceLayout.swift` 使用纸间已有参数与页眉槽位表达这些关系；不同字体和渲染引擎不承诺逐像素相同。补丁不含第三方 CSS、字体、图标或 IPA。

书源适配范围：识别有地址的段/章评论标记、已识别的显示评论动作和显式链接，保留数量；原生卡片读取常见 JSON 的作者、正文、点赞数。缺正文、拒绝请求与确实空列表分开反馈；HTML、需要手动登录或不识别的结构可转到书源原网页。不会因为打开书就发起评论请求，也不执行正文中的任意点击脚本。没有公开可用接口的源不能凭空生成段评。

## P6 设计讨论（未改产品）

建议先选首页「续读」作对照：同一本书、同一进度、同一设备，保留森林绿、书影玻璃和展台。让封面和书名先被看到，把章节和进度归为一行，只突出「继续阅读」；书架仍紧接其下。另一条路线是让首屏展示更多本书，代价是当前书不那么突出。先选要优先服务哪件事，再画一屏比较，不从评价截图推断该换品牌。
