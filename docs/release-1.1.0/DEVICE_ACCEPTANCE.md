# 1.1.0 / 120 设备验收

目标：iOS16.x一台+当前iOS一台；Windows和较新CI模拟器不能代替。保留119 IPA，升级前导出应用数据备份，不通过卸载清空数据掩盖问题。

## 发布阻断项

1. 从22章打开目录，第一次拖到29章，停住不回弹。选29章后上下滑，不回22章。重复10次，再测连续跳章、逆序、过滤。
2. TXT/EPUB各连续打开关闭右上角详情10次，不卡死/退出，返回保持原页。
3. 所有已有翻页方式逐页读两章再反向回来；对照首尾，不丢字/重复段/跨错章。小中大字体，含“抽烟。”紧接汉字的引号样本。
4. 正文选择长按、拖手柄、复制、系统菜单不能被点击区域抢走；“完成选择”后区域操作恢复；设置不被按钮遮挡。
5. 朗读/自动滚动跨段跨章正常跟随，手动跳章不被旧朗读回调拉回。
6. 冷启动进长章立即轻滑；分别测缓存/网络章，记录视频和诊断；掉帧需Instruments采样，不能用测试计数代替。

## 功能覆盖

- 书架恢复、旧进度、缓存/离线、切源、刷新、目录正反序与过滤、书签、朗读、图片章。
- 搜索20/100条、慢封面、快速改词/匹配模式/分组。详情一快一慢、超时和切源取消，旧任务不能覆盖新书/新源。
- 主色/辅色明显切换，遍历根标签并重启，再恢复默认；正文主题不变，浅深色可读。
- 源列表长名字/大字/小屏，标签不竖排，登录/详情/更多均可点。
- 登录中心当前网页提取/返回，Cookie和导航位置保留；提取中同URL刷新不得回旧结果。
- 广告开关、用户主动新链接、自动弹窗、正常章节；规则可关闭，不保证所有首方广告。
- 设置品牌、诊断详情/单条与全部复制、内容过滤、菜单去重、自动亮度状态。
- LAN手机Safari与桌面真实连接，推送测试源、固定页解析调试、源库刷新。浏览器固定API测试不等于这一步。
